# Real Estate App - Frontend

نظام إدارة العقارات - واجهة المستخدم

## المميزات

- 📊 لوحة تحكم شاملة
- 📝 إدارة العقارات (إضافة عقار جديدة)
- 🏠 إدارة الوحدات (إضافة وحدات داخل العقارات)
- 📄 إدارة العقود
- ⚡ إدارة العدادات (الكهرباء والماء)
- 💰 حساب الفواتير تلقائياً
- ⚠️ تنبيهات واضحة

## التقنيات

- HTML5
- CSS3
- JavaScript (ES6+)

## تشغيل المشروع

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend
```bash
cd frontend
python3 -m http.server 5173
```

ثم افتح: http://localhost:5173
